====================================================================
BYOVD CASE-TO-TARGET SUMMARY (NOTEPAD EXPORT)
====================================================================

Primary Risk:    High (Arbitrary Hardware Access & Memory Primitives)

--------------------------------------------------------------------
IOCTL CODE: 2241736 (LowPart - 2241736 == 0)
--------------------------------------------------------------------
- Target Operation:  PCI Configuration Read
- Access Type:       HalGetBusDataByOffset / Information Disclosure
- Mechanism:         Exposes low-level device configuration space to user-mode.
- Security Impact:   Allows low-privileged applications to query hardware bus configurations.

--------------------------------------------------------------------
IOCTL CODE: 2241740 (LowPart - 2241736 == 4)
--------------------------------------------------------------------
- Target Operation:  PCI Configuration Write
- Access Type:       HalSetBusDataByOffset / Hardware Modification
- Mechanism:         Permits user-mode modification of hardware bus settings.
- Security Impact:   Enables unauthorized reconfiguration of physical device registers.

--------------------------------------------------------------------
IOCTL CODE: 2241744 (LowPart - 2241736 == 8)
--------------------------------------------------------------------
- Target Operation:  Spinlock-Protected Pointer Read
- Access Type:       Arbitrary Memory Read Primitive
- Mechanism:         Reads 1, 2, or 4 bytes from target memory offsets controlled via input.
- Security Impact:   Can be used to leak kernel addresses or bypass KASLR.

--------------------------------------------------------------------
IOCTL CODE: 2241748 (LowPart - 2241736 == 12)
--------------------------------------------------------------------
- Target Operation:  Spinlock-Protected Pointer Write
- Access Type:       Arbitrary Memory Write Primitive
- Mechanism:         Writes 1, 2, or 4 bytes to target memory offsets.
- Security Impact:   Core primitive for token stealing and privilege escalation to SYSTEM.

--------------------------------------------------------------------
IOCTL CODE: Upper Range (LowPart > 0x2234DC)
--------------------------------------------------------------------
- Target Operation:  Conditional Memmove & Structure Copying
- Access Type:       Kernel Information Disclosure
- Mechanism:         Dumps internal driver objects, telemetry blocks, or state descriptors to user-mode.
- Security Impact:   Leaks internal driver state or kernel structures.
